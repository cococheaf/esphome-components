# ESP8266 + CC1101 setup

The tested configuration uses a Wemos D1 Mini (ESP8266), a CC1101 at
868.95 MHz, and a Diehl IZAR water meter. Start with
[the example](../examples/esp8266-cc1101-izar.yaml) and adapt the pins and
meter to your own hardware.

## Wiring

| CC1101 | D1 Mini GPIO | D1 Mini label |
| --- | --- | --- |
| VCC | 3.3 V | 3V3 |
| GND | GND | G |
| SCK | GPIO14 | D5 |
| MOSI | GPIO13 | D7 |
| MISO | GPIO12 | D6 |
| CSN | GPIO15 | D8 |
| GDO2 | GPIO4 | D2 |

Use a **3.3 V** CC1101 module and suitable power supply. The ESP8266 path
expects GDO2 as the early sync-word interrupt. GDO0 is not required for this
configuration. Other boards may need different pins.

## From version 3 to version 5

1. Save a copy of the working YAML and record the current entity IDs.
2. Replace `wmbus:` with `spi:` and `wmbus_radio:`.
3. Add a `wmbus_meter:` entry with the meter type and its version 5 address.
4. Replace `platform: wmbus` sensors with `platform: wmbus_meter`, a
   `parent_id`, and fields such as `total_m3`, `rssi_dbm`, and `lqi`.
5. Compile first. Then flash, watch live logs, and verify a real reading in
   Home Assistant. Restore original entity IDs if the integration creates
   new ones so dashboards and automations keep working.

The address in a version 3 configuration is not necessarily the version 5
address. Read the `Check if telegram with address ...` line in the version 5
log and use that value as `meter_id`. In the tested IZAR installation,
`0x71840778` became `0x23537184`; this is an example, **not** a universal
conversion rule.

## Runtime checks

The meter total may stay unchanged between broadcasts even while reception is
healthy. RSSI and LQI updating on received telegrams are useful diagnostics.
If `Telegram not handled` repeats, verify the configured address first.
If `RX FIFO overflow` repeats and readings stop, reduce excessive logging,
check GDO2 and SPI wiring, and ensure stable power. ESP8266 reception is more
timing-sensitive than the ESP32 FreeRTOS receiver; it is not guaranteed for
every meter, frame length, or radio board.
